# İstatistiksel Analiz Raporu

## 1. Genel İstatistikler (2011-2013)

### 1.1 Yıllara Göre Kayıp Çocuk Vakaları

```
| Yıl  | Evden Kaçma | Kayıp (Bulunan) |
|------|-------------|----------------|
| 2011 | 3,222       | 10,067         |
| 2012 | 2,424       | 12,474         |
| 2013 | 2,821       | 16,218         |
```

### 1.2 Önemli Bulgular

1. Kayıp çocukların %70'i evden kayıp çocuklardır
2. %30'u kurumlardan kayıp vakalarıdır
3. Kaybolma sebepleri:
   - Gönül ilişkisi
   - Eğlence/macera amaçlı
   - Evlenme amaçlı
   - Aile içi huzursuzluk
   - Aile içi şiddet
